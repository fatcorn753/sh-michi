# シェルのみち

ブラウザだけで Linux のコマンドを学べる練習サイトです。インストールもアカウントも要りません。本物のサーバーには触れないので、消しても壊しても大丈夫です。

## 特徴

- **ファイルの木を見ながら打つ。** コマンドを 1 行ずつ動かし、いまいる場所、増えた・変わった・消えたファイルを木の図で示します。パイプでは、各段が次へ渡した中身も見られます。
- **本物と同じ英語のエラーに、日本語の説明を添える。** `No such file or directory` や `Permission denied` が出たとき、何が起きたかと次に打つものを説明します。
- **読む → 予測する → 書く の順に練習する。** 例題、出力の予測、行の並べ替え、穴埋め、白紙から書く問題を、単元ごとにこの順で解きます。採点は画面の出力だけでなく、終わったときのファイルといる場所も比べます。
- **身に付いたかを測る。** 確認テストに合格すると次の単元が開きます。忘れかけたころに、名前や数を変えた問題で復習します。
- **自由に打つ画面。** 練習用のファイルが置かれた端末で、好きなコマンドを試せます。

記録はブラウザの中(localStorage)にだけ保存されます。

## 内容

| 単元 | 主なコマンド |
|---|---|
| ① いまいる場所 | pwd / ls / cd、絶対パスと相対パス |
| ② ファイルを作る・動かす・消す | mkdir / touch / cp / mv / rm |
| ③ 中身を見る | cat / head / tail / wc |
| ④ パイプとリダイレクト | `\|` / `>` / `>>` / `<` / `2>` / `2>&1` |
| ⑤ 探す・並べる・数える | grep / cut / sort / uniq |
| ⑥ 権限 | ls -l の rwx と持ち主、chmod、whoami / id |
| ⑦ ワイルドカードと find | `*` / `?` / `[...]`、find -name / -type |

作品コース「ログ調査」では、あるサーバーの認証ログ(/var/log/auth.log)から、総当たり攻撃の攻撃元と狙われた名前を数え、侵入した相手と sudo で実行されたコマンドを突き止めて、報告書にまとめます。ログの IP は、文書用に予約された範囲だけを使っています。

## 使えるシェルの範囲

自作の小さなシェル(TypeScript)が、ブラウザの中の仮のファイルシステムの上で動きます。

- 書き方: 引用符(`'` `"` `\`)、`|`、`>` `>>` `<` `2>` `2>&1`、`;` `&&` `||`、`*` `?` `[...]`、`~`、`$変数`
- コマンド: pwd ls cd cat echo mkdir touch rm rmdir cp mv head tail wc grep sort uniq cut tr find chmod whoami id help man clear
- 出力の書式は GNU coreutils(C ロケール)に合わせています

`$( )`、`if` や `for` などのスクリプト、本物のプロセスやネットワーク、エディタには対応していません。

## 開発

```bash
npm install
npm run dev      # 開発サーバー
npx vitest run   # シェルと全教材の検査
npm run build
```

- `src/shell/` — 字句解析・構文解析・展開・リダイレクト・仮のファイルシステム・各コマンド
- `src/content/` — 教材。正解の出力は書かず、参照解を実行して求めます
- `src/learn/` — 習得度の推定(BKT)、復習の予定、採点、記録
- `src/ui/` — 画面
